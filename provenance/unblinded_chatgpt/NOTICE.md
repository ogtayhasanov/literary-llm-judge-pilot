# Preliminary unblinded self-scoring

These files preserve the earlier exploratory scoring from the same ChatGPT conversation that authored the cases and had already seen which quotations were altered. The scores and preferences are context-contaminated. They are not an independent judge and are **not** used in the Claude results.

`analyze_pilot.py` reproduces the preliminary calculations using the files in this directory. They are retained so the complete development history can be inspected, not as evidence of performance for an additional blinded model.
